# Cas d’usage — B2B/CIAM

## Contexte
Accès partenaires et/ou clients (volumétrie + fraude).

## Exigences typiques
- parcours d’inscription, récupération de compte
- consentement & confidentialité
- limitation brute-force, détection bots
- MFA adaptative (risk-based)

## Pattern recommandé
- séparation stricte tenants/partenaires
- politiques d’auth adaptatives
- journaux d’audit exploitables fraude
- APIs sécurisées (OAuth scopes/audiences)
