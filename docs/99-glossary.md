# Glossaire

- **AuthN** : authentification (preuve d’identité)
- **AuthZ** : autorisation (droits d’accès)
- **IdP** : Identity Provider
- **SP** : Service Provider
- **MFA** : Multi-Factor Authentication
- **Passkey** : authentification FIDO/WebAuthn (phishing-resistant)
- **SCIM** : protocole de provisioning utilisateurs/groupes
- **PAM** : Privileged Access Management
- **ITDR** : Identity Threat Detection & Response
- **PDP/PEP** : Policy Decision Point / Policy Enforcement Point
- **RBAC/ABAC/ReBAC** : modèles d’autorisation
- **JIT/JEA** : Just-In-Time / Just-Enough-Administration
