# Standards & protocoles (référence)

## Authentification & Fédération
- **OIDC** : standard de facto pour applications modernes.
- **SAML2** : très présent pour le legacy et certaines fédérations B2B.

## OAuth (autorisation API)
- **RFC 9700** : bonnes pratiques de sécurité OAuth 2.0 (BCP).
- **OAuth 2.1 (draft)** : consolidation des meilleures pratiques.

## Provisioning
- **SCIM 2.0 (RFC 7644/7643)** : standard provisioning (utilisateurs/groupes).

## Passwordless
- **FIDO2 / WebAuthn / Passkeys** : authentification résistante au phishing.

## Signaux & continuous access
- **SSF / CAEP / RISC** : partage d’événements de sécurité, réévaluation de session.

## Profils prescriptifs
- **FAPI 2.0 Security Profile** : exigences renforcées pour APIs à haut risque.
